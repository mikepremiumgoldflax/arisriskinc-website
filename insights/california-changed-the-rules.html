Twelve measures for rates

California’s direction of travel on wildfire mitigation is a set of twelve measures that can bear on rates. The direction is real. It is not a requirement to buy a catastrophe model, and it is not a requirement to buy ARIS.

How a filing treats those measures is a regulatory and actuarial question. It will not read the same way in every filing. This note is not a compliance opinion, and it does not list the twelve measures as a checklist to file against.

Twelve measures for rates. Directional. Not a mandate to buy a model.

Where the engine fits

Mitigation on ARIS is a use of the catastrophe model, not a second product and not a certificate of compliance. Before the season, the same engine can target where work changes the probability a structure is reached and lost. It can support the plan for that work. After the work is done, it can rescore the parcel.

Pricing-grade parcel scores, portfolio and accumulation views, and exceedance-probability output in open insurer standards come from that same run. Response intelligence — the view while a fire is underway — is a concept demonstration, available in 2027.

What stays checkable

The model is physics-based and parcel-resolved. In public, the architecture is physics-based, two-stage, sealed and graded. The forecast is sealed before the season, the grading method is sealed, and the grade is published whatever it says. Results are 100% reproducible bit-for-bit.
